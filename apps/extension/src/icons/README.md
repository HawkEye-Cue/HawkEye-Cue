# Extension Icons

Replace these placeholder files with actual hawk icon PNG files:

- `hawk-16.png` — 16x16 px (toolbar icon, small)
- `hawk-48.png` — 48x48 px (extension management page)
- `hawk-128.png` — 128x128 px (Chrome Web Store listing)

Use a hawk/eagle icon with amber/gold coloring on a dark background to match the HawkEye-Cue brand.

You can generate these from the existing `/apps/web/public/hawk.jpg` image, resized and cropped appropriately.
