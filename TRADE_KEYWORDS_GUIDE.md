## 🎯 Using Trade-Specific Keywords

### Step 1: View Current Trade Keywords

1. Go to **More** → **🔍 Keyword Tracking**
2. See your current trade at top (with icon)
3. View default keywords for that trade
4. Add custom keywords as needed

### Step 2: Keywords Auto-Sync

- **Add keyword** → Automatically syncs to extension
- **Delete keyword** → Automatically removed from extension
- **Edit keyword** → Extension updates instantly

### Step 3: Switch Trades

1. Go to **More** → **Change Industry**
2. Select different trade
3. Go back to **Keyword Tracking**
4. **New trade's keywords automatically load!**
5. Extension starts monitoring new keywords

## 🎨 Customizing Keywords

```

```

## 🔧 Advanced Tips

### Location-Specific Keywords

Add your city/area:
```
[Your City] + [trade]
- "Brighton roofer"
- "Denver plumber"
- "local electrician"
```

### Problem-Based Keywords

What problems do people post about?
```
Roofer:
- "water coming through ceiling"
- "shingles blowing off"
- "ice dam"

Plumber:
- "toilet won't flush"
- "no hot water"
- "sewer smell"
```

### Seasonal Keywords

```
Roofer (Spring):
- "storm damage"

- "ice dam"
- "snow removal"

HVAC (Summer):
- "ac not cooling"
- "ac broke"

- "heat not working"
- "furnace out"
```
