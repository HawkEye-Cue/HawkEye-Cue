# HawkEye-Cue

Social media scheduler built for local businesses - never miss a lead on Facebook again.

## Features

- 🦅 Facebook Keyword Tracking with Chrome Extension
- ✨ AI-Powered Post Creation
- 📅 Smart Scheduling & Daily Cues
- 🎯 Opportunities Tracking
- 🗺️ Territory Management
- 📊 Advanced Analytics

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- Motion (Framer Motion)
- Lucide Icons

## Development

```bash
# Install dependencies
pnpm install

# Run dev server
pnpm dev

# Build for production
pnpm build
```

## Deployment

Deployed on Vercel with continuous deployment from main branch.
